# 🌸 Perfumy – Perfume E-Commerce Website

A modern and elegant perfume shopping website built using **React.js**. This project showcases a collection of perfumes through a clean and attractive user interface, focusing on reusable components, dynamic product displays, and responsive web design.

## 🌐 Live Demo

https://perfumy-react-1l50cqhth-tttt-e5c3.vercel.app/

## 📌 About The Project

Perfumy is a React-based perfume e-commerce frontend application designed to provide users with a simple and enjoyable browsing experience.

The website displays different perfume products with their images and descriptions. It was developed as a practical learning project to improve frontend development skills and understand how React components work together to build interactive web applications.

## ✨ Features

- **Modern UI:** Clean and attractive perfume shopping interface.
- **Product Display:** Showcases different perfume products with images and descriptions.
- **Reusable Components:** Built using reusable React functional components.
- **Component-Based Architecture:** Organized the application into separate components for better readability and maintenance.
- **Search Functionality:** Helps users find products easily.
- **Responsive Design:** Provides a user-friendly layout across different screen sizes.
- **React Props:** Used props to pass data between components.
- **Dynamic Rendering:** Used JavaScript concepts to display product information.

## 🛠️ Technologies Used

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd PERFUMY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
